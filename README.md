# Komiko Grab-n-Go 🐷

*made by [softbellypig](https://github.com/softbellypig)*

Saves every image from your Komiko (komiko.app) generations page into a folder
named with today's date and time. Two clicks, then go have a snack.

> **Unofficial.** This is an independent fan-made tool. It is not affiliated
> with, endorsed by, or supported by Komiko / KomikoAI. It only saves images
> you generated on your own account.

## Install (one time, ~1 minute)

1. Unzip this folder somewhere you'll keep it (don't delete it later — Chrome
   runs the extension from here).
2. In Chrome, go to `chrome://extensions`.
3. Turn on **Developer mode** (toggle in the top-right).
4. Click **Load unpacked** and pick the `KomikoGrab_ext` folder.
5. Optional: click the puzzle-piece icon in Chrome's toolbar and **pin** Komiko Grab-n-Go.

## Use

1. Open your generations page on **komiko.app**.
2. **Scroll all the way to the bottom** so every image has loaded.
3. Click the 🐷 Komiko Grab-n-Go icon → **Scan all images**.
4. Check the count looks right → **Download all**.
5. A little window opens. **Keep it open** and let it run — go have a snack.
6. When it says *All done!*, click **Open folder**.

Files land in:

```
Downloads / Komiko / 2026-09-02_14-30 / komiko-0001.jpg, komiko-0002.jpg, ...
```

## Tips

- If Chrome asks *where to save* every single file, turn off
  **Settings → Downloads → "Ask where to save each file before downloading"**.
- If the count looks low, you probably didn't scroll far enough — scroll to the
  very bottom, wait a moment, and scan again.
- A few images "couldn't be saved"? Just scan and download again later; they
  usually go through the second time.
- Files landing straight in Downloads instead of the `Komiko` folder? Another
  extension (a download manager or image grabber) is overriding download
  locations. Either disable it while you grab, or remove and re-add Komiko
  Grab-n-Go so it's the newest installed — Chrome lets the newest one decide.
- This only works on komiko.app on purpose. It never contacts any other site.
